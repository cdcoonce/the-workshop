# Reading the Signal

A drill is worth running only if the misses are interpretable. This file is how
to interpret them and what to do next.

## The core discriminator

Ask the same concept twice — once as an abstract identity or definition, once
against concrete instances — and the pattern of misses separates two very
different problems:

| Abstract | Concrete | Diagnosis |
|---|---|---|
| miss | correct | **Recall gap.** The concept is understood; the notation, name, or default is not memorized. Flashcards, not a lesson. |
| correct | miss | **Applied gap.** A memorized rule that cannot be executed. Drill worked examples. |
| miss | miss | **Comprehension gap.** Teach it. |
| correct | correct | Floor. Stop drilling. |

This distinction is the skill's whole reason to exist. Prose teaching cannot
surface it, because someone who understands a mechanism will follow an
explanation of it fluently and both parties will conclude it landed.

## On a miss

1. **Say what the chosen option actually does**, not just what the right one
   does. "That expression evaluates to `r`, so it removes nothing" beats "the
   answer was the other one." A wrong option the person cannot see through stays
   available next time.
2. **Get concrete.** Run the real instances. Most recall misses convert the
   moment the abstraction has objects in it.
3. **Give a hook, not a correction** — a rule of thumb that regenerates the fact
   rather than a fact to re-memorize.
4. **Retest with fresh surface content.** Never re-ask the item verbatim, and
   re-randomize the position. A verbatim retest measures memory of the option
   text, which the person just read.

## When repetition bounces

A wrong answer carrying a **plausible artifact** — a real number, a real name
lifted from the material — resists correction. Stating the right answer once,
twice, three times does not displace it, because the artifact is genuinely
present in the source and feels like it belongs.

**Give the artifact a different job.** Show where it actually appears and what
claim it actually serves. The misconception is displaced by reassignment, not by
repetition. Observed: a figure that appeared as scene-setting context was twice
selected as a threshold, and converted immediately once the two roles were
distinguished.

If an item misses twice with the *same* wrong answer, stop repeating and reframe.

## Environment gaps

When someone's daily tools do not exercise the standard being tested, the gap is
environmental, not cognitive — a professional habit formed where the rule never
fires. Name it when you see it. It tells the person the fact needs deliberate
memorizing rather than leaving them to conclude they misunderstood something.

## Banking the result

If a persistent learning workspace exists for the topic, write the outcome there
rather than leaving it in the conversation:

- What was demonstrated, with the evidence — this raises the floor and should
  stop future sessions re-teaching it.
- What leaked, categorized by the table above.
- Any calibration question the drill settled or opened.
- Consequences for what to teach next, including lessons now cancelled as
  below-floor.

Absent a workspace, close with the same content as a summary. A diagnosis that
is not written down has to be re-earned.

## Honesty

Report the tally as it happened. If a result was compromised — a leaked pattern,
an ambiguous item, an answer the user says they guessed — say so and re-establish
the signal before drawing conclusions from it. A drill that overstates mastery is
worse than no drill, because it redirects study away from the real gap.
