# Drill Protocol

How to build and run the drill. The position-randomization mandate lives on
SKILL.md because it must survive without this file being loaded.

## Sourcing items

Drill the material, not your memory of the subject. Read the supplied notes,
slides, or code first and build items from what they actually say.

- If a fact is your inference rather than a stated claim, either drop it or mark
  it as inference when you grade. Never grade someone wrong against a fact the
  material does not contain.
- If the material is unavailable, say so and drill only what can be grounded.
- Where two sources disagree, that disagreement is worth an item on its own —
  and worth flagging as unresolved rather than picking a side silently.

## Building an item

A stem, two to four options, exactly one defensible answer.

**Rationale parity is the rule that makes it an assessment.** Write every
option's rationale as if it were correct — same length, same confidence, same
specificity. An option set where only the right answer is argued through can be
solved without reading the stem, which measures nothing.

Signals that leak the answer, all to avoid: the correct option being the
longest, the only one with a worked justification, the only one free of hedging,
or the only one using the material's exact vocabulary.

### Distractors that earn their slot

Each wrong option should be a misconception someone actually holds:

- **The flip** — the relationship reversed. (Constraint on the wrong side.)
- **The skipped condition** — right rule, missing precondition.
- **The plausible artifact** — a real number or name from the material,
  repurposed as an answer to a question it does not answer.
- **The near-miss definition** — a sibling concept that differs in one clause.
- **The over-generalization** — the rule stated without its exception.

Filler options inflate the score. If you cannot name the misconception a
distractor encodes, replace it.

**Do not use right-answer-wrong-reason as a distractor.** In multiple choice the
label is what gets selected; punishing a correct label for a wrong rationale is
unfair and untestable. Probe reasoning with a follow-up item instead.

## Cadence

One question per turn adapts; a batch is faster. Default to one at a time when
the goal is diagnosis, batch when the user wants volume before a deadline. Ask
which if the drill will run long.

Grade in one line before the next item. Do not accumulate a grading backlog —
the point of grading immediately is that it steers the next question.

## Coverage and adaptation

Weight items toward the suspected gap, but include items from the presumed floor
too: confirming they are free points is cheap, and floors are often wrong in both
directions.

- Two clean answers in an area — stop drilling it and say so.
- An effortless answer — raise difficulty, or move to a harder variant of the
  same concept rather than a new topic.
- Two misses in one area — drop difficulty and get concrete before continuing.
- Never pad the drill to a round number. Stop when the diagnosis is stable.

## Ending

Report an honest tally and the **shortest possible study list** — only the items
that actually leaked. A drill that ends with "review everything" wasted the
diagnosis it just produced.
